# 🤖 Telegram Scheduler & Autoposter Bot (Бот для отложки контента)

Telegram-бот для автоматической раскладки пачек медиафайлов (фото, видео, анимации, альбомы, документы, тексты) по фиксированным временным интервалам (слотам отложки).

Архитектура и UX воспроизведены на основе реальной системы планирования (исходный референс: `ChatExport_freeman`).

---

## ⚡️ Как это работает

1. **Подключение каналов**:
   - Добавляете бота администратором в ваш канал с правом публикации.
   - Отправляете `@channel_username`, ID (`-100...`) или пересылаете любой пост из канала.
   - Бот проверяет статус админа и сохраняет канал в базу.
   - Можно подключать неограниченное количество каналов и переключаться между ними.

2. **Настройка интервалов отложки (Расписание)**:
   - В меню канала нажимаете **«⏰ Расписание»**.
   - Пишете интервалы в любом удобном виде: `15,18` или `14:00, 21:00` или `9 12 15 18 21`.
   - Бот сохраняет слоты и подтверждает добавление.

3. **Настройка подписи (Caption)**:
   - В меню канала нажимаете **«✍️ Подпись»**.
   - Вводите текст подписи (поддерживается HTML-разметка, ссылки, эмодзи).
   - Подпись автоматически будет прикрепляться ко всем публикуемым медиафайлам, если у них нет своей персональной подписи.

4. **Массовая отложка (Планировщик постов)**:
   - Нажимаете **«📝 Запланировать посты»**.
   - Бот показывает текущее расписание и время последнего запланированного поста в очереди.
   - Вы кидаете в диалог пачку медиафайлов (10, 20, 50 штук) — сразу или по одному.
   - **Алгоритм автоматической раскладки**:
     - Если слоты заданы как `15:00` и `18:00`:
       - Файл #1 ➔ сегодня 15:00 (если время еще не прошло)
       - Файл #2 ➔ сегодня 18:00
       - Файл #3 ➔ завтра 15:00
       - Файл #4 ➔ завтра 18:00
       - Файл #5 ➔ послезавтра 15:00
       - Файл #6 ➔ послезавтра 18:00
       - ... и так далее последовательно по календарю!
     - Если в очереди уже есть посты до определенного дня, новые посты автоматически встают в очередь со следующего свободного слота!
   - На каждый присланный файл бот мгновенно отвечает:
     ```
     1. Планируемое время поста: DD.MM.YYYY 15:00
     [Предпросмотр медиафайла с подписью]
     ```
   - Завершение сессии:
     - Кнопка **«Готово»** ➔ сохраняет и фиксирует всю очередь («Добавление контента завершено»).
     - Кнопка **«Отмена»** ➔ удаляет добавленные в текущей сессии посты («Добавление контента отменено»).

5. **Фоновая автоматическая публикация**:
   - Асинхронный фоновый демон сканирует БД каждые 15 секунд.
   - Как только наступает время поста (`publish_at <= now()`), бот мгновенно публикует его в канал через Telegram Bot API и фиксирует статус.

## 🏗 Архитектура проекта

```
tg_autoposter/
├── bot.py                  # Главная точка входа: запуск бота, диспетчера и фонового воркера
├── config.py               # Настройки, чтение переменных окружения (.env)
├── database/
│   ├── __init__.py
│   └── models.py           # Асинхронные модели SQLite (aiosqlite): каналы, посты, очереди
├── handlers/
│   ├── __init__.py
│   ├── start.py            # /start, главное меню, справочная система
│   ├── channel.py          # Меню каналов, добавление, расписание (15,18), подписи, очередь
│   └── planner.py          # Прием пачек медиа, расчет календарных слотов, превью, Готово/Отмена
├── keyboards/
│   ├── __init__.py
│   ├── reply.py            # Reply-клавиатуры (Готово, Отмена, Назад)
│   └── inline.py           # Inline-кнопки меню, списков каналов и управления
├── middlewares/
│   ├── __init__.py
│   └── album.py            # AlbumMiddleware для авто-склейки медиагрупп (альбомов)
├── services/
│   ├── __init__.py
│   └── scheduler.py        # Алгоритм раскладки слотов + фоновый движок публикации
├── tests/
│   └── test_scheduler.py   # Набор автоматических тестов логики и БД
├── run.sh                  # Исполняемый скрипт быстрого запуска
├── .env.example            # Шаблон конфигурации
└── README.md
```

## 🚀 Запуск и настройка

### 1. Подготовка конфигурации

Скопируйте пример файла настроек:
```bash
cp tg_autoposter/.env.example tg_autoposter/.env
```

Откройте `tg_autoposter/.env` и впишите токен вашего бота (полученный у `@BotFather`):
```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
TIMEZONE=Europe/Moscow
```

### 2. Проверка и тесты

Запустите автоматические тесты:
```bash
PYTHONPATH=tg_autoposter esoteric_growth_engine/.venv/bin/python tg_autoposter/tests/test_scheduler.py
```

### 3. Запуск бота

Используйте скрипт:
```bash
./tg_autoposter/run.sh
```

Или напрямую:
```bash
cd tg_autoposter
PYTHONPATH=. ../esoteric_growth_engine/.venv/bin/python bot.py
```
